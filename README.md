# Movie Search

## Description
Search for Movies or TV show using a built in searchbar that recognizes keywords. Uses TVMaze API

## Technologies
- SCSS (SASS)
- HTML
- JS
- Axios CDN

## Features
- Sleek one page look
- Search bar for movies / TV shows
- Movie/show cards with descriptions
